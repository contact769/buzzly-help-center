# Memberful

Turn Memberful signups into newsletter subscribers — no plan restriction, this is the simplest of these integrations to set up.

## Steps

1. In Buzzly, generate your webhook URL above and copy it.
2. In [Memberful](https://memberful.com), go to Settings → Webhooks.
3. Add the URL as an endpoint.
4. Save, then create a test member to confirm it arrives.

## Troubleshooting

**Nothing arrives.** Double-check the endpoint was saved in Memberful's Webhooks settings — no additional plan or activation step is required.
