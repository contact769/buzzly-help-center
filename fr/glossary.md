# Glossaire

Les mots que vous croiserez dans Buzzly, expliqués simplement.

← Retour à l'**[accueil du Centre d'aide](./README.md)**

---

| Terme | Ce que cela signifie |
|---|---|
| **Post** | Un numéro de newsletter — ce que vous rédigez et envoyez. Voir **[Créer des posts](./creating-posts.md)**. |
| **Brouillon** | Un post enregistré mais pas encore envoyé ni publié. |
| **Post programmé** | Un post configuré pour partir automatiquement à une date et heure futures. |
| **Bloc** | Une brique d'un post (titre, paragraphe, image, bouton, etc.). |
| **Modèle d'e-mail** | Un design de post enregistré et réutilisable. Voir **[Modèles d'e-mail](./email-templates.md)**. |
| **Abonné** | Une personne qui reçoit votre newsletter. Aussi appelé **lecteur**. Voir **[Gérer les abonnés](./managing-subscribers.md)**. |
| **Diffusion** | Le nom interne, dans Buzzly, de votre liste d'abonnés. |
| **Thème (étiquette)** | Un libellé pour organiser les posts et regrouper les abonnés. Voir **[Thèmes & étiquettes](./themes-and-tags.md)**. |
| **Préfixe** | Le nom court unique dans votre adresse web, ex. `votrenom` dans `votrenom.mybuzzly.com`. Choisi à l'inscription et définitif. |
| **Créateur de site** | L'outil visuel, sans code, pour construire votre site public. Voir **[Votre site web](./website-builder.md)**. |
| **Section** | Un bloc réutilisable de votre site (hero, articles, formulaire d'inscription, FAQ, etc.). |
| **Link in Bio / Blog simple / Site d'actualité** | Les trois styles de site que vous pouvez choisir. |
| **Taux d'ouverture** | La part d'abonnés ayant ouvert un e-mail donné. Voir **[Statistiques](./analytics.md)**. |
| **Taux de clic** | La part d'abonnés ayant cliqué un lien dans votre e-mail. |
| **Monétisation** | Gagner de l'argent avec votre newsletter via des abonnements payants. Voir **[Monétisation](./monetization.md)**. |
| **Palier** | Une offre payante proposée à vos lecteurs (ex. « Soutien — 5 €/mois »). |
| **Stripe** | La société de paiement de confiance qui traite les paiements des lecteurs et vous verse vos gains. |
| **Stripe Connect** | La configuration qui relie votre compte bancaire pour être payé directement. |
| **Post premium** | Un post que seuls les membres payants peuvent lire en intégralité. |
| **Programme de parrainage** | Un système qui récompense les lecteurs qui invitent leurs amis. Voir **[Parrainage](./referrals.md)**. |
| **Palier de parrainage** | Un objectif de parrainage (ex. 5 amis) qui débloque une récompense. |
| **Intégration** | Une connexion entre Buzzly et un autre outil, comme Discord. Voir **[Intégrations](./integrations.md)**. |
| **Offre Buzzly** | Votre propre abonnement à Buzzly (Starter / Pro / Premium). Voir **[Réglages](./settings.md)**. |
| **E-mail de bienvenue** | Un message automatique reçu par les nouveaux abonnés lors de leur inscription. |
| **CSV** | Un simple fichier tableur (`.csv`) utilisé pour importer des abonnés en masse. |
