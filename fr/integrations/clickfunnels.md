# ClickFunnels

Transformez vos contacts ClickFunnels en abonnés à votre newsletter.

## Étapes

1. Générez votre URL dans Buzzly et copiez-la.
2. Dans [ClickFunnels (2.0)](https://www.clickfunnels.com), allez dans Workspace Settings → Webhooks → Add New Endpoint.
3. Collez l'URL et sélectionnez l'événement `contact.created`.
4. Enregistrez, puis soumettez un contact test via votre funnel.

## Dépannage

**Rien n'arrive.** Vérifiez que vous avez bien sélectionné `contact.created` — ClickFunnels propose plusieurs événements aux noms proches.
