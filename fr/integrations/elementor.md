# Elementor

Transformez les soumissions de vos formulaires Elementor en abonnés à votre newsletter.

## Étapes

1. Générez votre URL dans Buzzly et copiez-la.
2. Dans votre widget de formulaire [Elementor](https://elementor.com/help/actions-after-submit/), nommez votre champ email `email` et vos champs de nom `first_name`/`last_name`.
3. Ajoutez l'URL comme action Webhook dans les « Actions après soumission » du formulaire.
4. Enregistrez, puis envoyez une entrée test.

## Dépannage

**La règle du nom de champ.** Le nom technique du champ doit rester en anglais, même si les libellés affichés sont en français.

**Pas de nom sur les abonnés.** Vérifiez que vos noms de champs correspondent à `email`/`first_name`/`last_name` — traduire le nom technique (et pas seulement le libellé) est la cause la plus fréquente des noms manquants.
