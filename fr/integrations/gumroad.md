# Gumroad

Transformez vos ventes Gumroad en abonnés à votre newsletter.

## Étapes

1. Générez votre URL dans Buzzly et copiez-la.
2. Dans [Gumroad](https://gumroad.com), allez dans Réglages → Avancé.
3. Collez l'URL comme point de terminaison Ping.
4. Enregistrez, puis effectuez un achat test (ou utilisez le mode test de Gumroad) pour confirmer.

## Dépannage

**Rien n'arrive.** Vérifiez que le champ Ping endpoint a bien été enregistré — Gumroad ignore silencieusement une URL invalide plutôt que d'afficher une erreur.
