# ManyChat

Transformez les données de vos conversations ManyChat en abonnés à votre newsletter.

## Étapes

1. Générez votre URL dans Buzzly et copiez-la.
2. Dans [ManyChat](https://manychat.com), nommez votre champ email `email` et vos champs de nom `first_name`/`last_name`.
3. Ajoutez l'URL comme action de requête externe (webhook) dans votre automatisation.
4. Enregistrez, puis testez en déclenchant le flux.

## Dépannage

**La règle du nom de champ.** Le nom technique du champ doit rester en anglais, même si le libellé affiché est en français.

**Pas de nom sur les abonnés.** Vérifiez que vos champs sont bien nommés `email`/`first_name`/`last_name` — traduire le nom technique du champ est la cause la plus fréquente des noms manquants.
