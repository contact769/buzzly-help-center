# Memberful

Transformez les inscriptions Memberful en abonnés à votre newsletter — sans restriction de forfait, c'est la plus simple de ces intégrations à mettre en place.

## Étapes

1. Générez votre URL dans Buzzly et copiez-la.
2. Dans [Memberful](https://memberful.com), allez dans Réglages → Webhooks.
3. Ajoutez l'URL comme point de terminaison.
4. Enregistrez, puis créez un membre test pour confirmer que ça fonctionne.

## Dépannage

**Rien n'arrive.** Vérifiez que le point de terminaison a bien été enregistré dans les réglages Webhooks de Memberful — aucun forfait ni étape d'activation supplémentaire n'est requis.
