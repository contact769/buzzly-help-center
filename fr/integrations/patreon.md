# Patreon

Transformez vos adhésions Patreon en abonnés à votre newsletter.

## Étapes

1. Générez votre URL dans Buzzly et copiez-la.
2. [Patreon](https://www.patreon.com) exige que vous créiez votre propre client dans son portail développeur.
3. Ajoutez l'URL comme point de terminaison de webhook pour les événements liés aux membres de ce client.
4. Enregistrez, puis déclenchez un événement membre test.

## Dépannage

**Un mécène n'apparaît pas après un vrai don.** Patreon a parfois été signalé pour envoyer une adresse email vide sur certains événements de membre — si un mécène n'apparaît pas comme abonné, c'est probablement la cause, pas un webhook cassé.
